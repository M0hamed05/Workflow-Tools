# ⚡ Workflow Tools

A collection of lightweight Windows desktop utilities built to save time and speed up daily workflows while studying or working.

---

## 🛠️ Included Tools

| Tool                           | Description                                                                                                                              | Built With                                    |
| :----------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------- |
| **1. Context Menu Studio**     | Customize Windows right-click menus, add custom developer submenus (`code .`, `cmd`, `npx`), and manage 1-click registry restore points. | .NET 9.0 (WPF) • Vibe coding with Antigravity |
| **2. Miller Columns Explorer** | A fast, lightweight (~280 KB) macOS Finder-style cascading columns file explorer for Windows with marquee selection and `Ctrl+Z` undo.   | .NET 8.0 (WPF) • Vibe coding with Antigravity |

---

## 1️⃣ Context Menu Studio

### ✨ Highlights

- **Custom Cascading Submenu:** Group commands like `code .`, `cmd`, `powershell`, and `npm run dev` under a single right-click submenu.
- **Smart Execution Modes:** Run commands silently in the background or keep the CMD window open for logs.
- **Live Preview Simulation:** See how your context menu looks in Windows Explorer before deploying.
- **1-Click Restore Points:** Automatic registry snapshots before every change for instant recovery.

## 2️⃣ Miller Columns Explorer

### ✨ Highlights

- **Cascading Miller Columns:** Navigate nested folders horizontally with smooth animations.
- **Windows Interoperability:** Rubber-band marquee selection, `Ctrl+Z` undo support, cross-column drag & drop, and native right-click context menus.
- **Dark & Light Themes:** Auto-detects Windows system theme with a collapsible sidebar.
- **Ultra-Lightweight:** Zero external dependencies (~280 KB standalone executable).
